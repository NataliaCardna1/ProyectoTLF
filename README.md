# Proyecto TLF — Búsqueda y Validación de Patrones

## Descripción
Aplicación desarrollada en Python para:
- Buscar patrones en textos.
- Validar formularios interactivos.
- Aplicar conceptos de Teoría de Lenguajes Formales.
- Implementar autómatas sin usar librerías regex.

## Componentes
- main.py → menú principal
- motor/ → motor de autómatas
- busqueda/ → buscador de patrones
- validacion/ → formularios interactivos

## Ejecución
python main.py
